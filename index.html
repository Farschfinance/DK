⚙ Setup-Anleitung (einmalig, kostenlos)

  1. Gehe zu console.firebase.google.com → Neues Projekt erstellen (z.B. "dunkle-karten")
  2. Im Projekt: Build → Realtime Database → Datenbank erstellen → Testmodus aktivieren
  3. Gehe zu Projekteinstellungen → Deine Apps → Web-App hinzufügen → Config kopieren
  4. In dieser HTML-Datei den firebaseConfig-Block (ca. Zeile 130) mit deinen echten Werten ersetzen
  5. Die fertige HTML-Datei auf GitHub Pages hochladen oder lokal öffnen – fertig!
